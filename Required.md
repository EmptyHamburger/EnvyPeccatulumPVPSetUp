# Required Files/Plugins/Programs

1. Download the latest versions of `EnvyPeccatulumPVP.dll` and `EnvyPeccatulumPVP.json` from the `Envy Peccatulum PVP` thread. Place both of these files in your `YourLetheFolder/BepInEx/plugins` folder

2. Download `IDToAbnor.exe` and its `config.json` file from `Identity to Envy Peccatulum` thread. Place both of these files in your `YourLetheFolder/BepInEx/plugins/Lethe/mods` folder
3. Download the `PVP Encounter Template` from `Identity to Envy Peccatulum` thread. Place the mod in your `YourLetheFolder/BepInEx/plugins/Lethe/mods` folder
